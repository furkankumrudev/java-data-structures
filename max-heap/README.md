# MaxHeap Event Manager

This project implements a Max Heap data structure in Java to simulate an event manager.

## Features
- Each event has a `priority` and a `lifespan`.
- Events are inserted and removed based on maximum priority.
- Lifespans are decremented over time; expired events are automatically removed.

## Usage
Run the `main` method to simulate the event insertion and processing.
