# Binary Search Tree (Java)

This project implements a Binary Search Tree (BST) in Java that self-balances after insertions and deletions.

## Features
- Insert, delete, and search operations
- Inorder, preorder, and postorder traversal
- Tree rebalancing via sorted list reconstruction
- Randomized test generation in `main` method

## How to Run
```bash
javac src/BinarySearchTree/BinarySearchTree.java
java -cp src BinarySearchTree.BinarySearchTree
```

## Output
Sample output will show inserted/deleted values, traversal results, and tree height.
