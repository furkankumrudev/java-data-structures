# Java Data Structures

A collection of data structure and algorithm implementations written in Java, built from scratch while studying at university.

| Folder | Contents |
|---|---|
| [`stack`](stack) | Array-based and linked-list-based stacks, postfix expression evaluation |
| [`queue`](queue) | Generic queue and generic circular queue |
| [`linked-list`](linked-list) | Doubly, circular and sorted-merge linked lists |
| [`binary-search-tree`](binary-search-tree) | Self-balancing BST with insert, delete, traversals and rebalance |
| [`max-heap`](max-heap) | Max heap used as a priority-based event manager |
| [`graph-tr-cities`](graph-tr-cities) | Graph of Turkish cities with BFS/DFS and adjacency matrix |
| [`sorting-benchmark`](sorting-benchmark) | Timing comparison of Selection, Insertion, Shell and Bubble sort |

Each folder is self-contained. Compile with `javac` and run the class that has a `main` method (see the folder's README where present).
